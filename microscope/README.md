# 显微功能（智能显微镜“微观有据”，feature/microscope 分支）

MaixCAM2 端的显微服务：清晰度、原图采集、原图取回、局域网预览。与 M10 和课堂电脑的消息约定见
smart-microscope 仓库的 `docs/protocol.md`。所有数字均为 2026-11-10 在本机实测，镜头为普通广角镜头（尚未装显微光路）。

| 文件 | 作用 |
|---|---|
| `scope_service.py` | 服务主程序：SIoT 收清晰度/拍照请求；HTTP 8091 提供原图、预览、状态 |
| `scope_camera.py` | 相机会话：拿小智的相机占用锁 → 打开相机；空闲 20 s 关相机放锁；假相机供电脑测试 |
| `sharpness.py` | 清晰度：观察区（默认中央 50%×50%）灰度拉普拉斯方差，三帧取中位数 |
| `run_scope.sh` | 启停脚本（停止走“停止文件”，先关相机再退出） |
| `tools/probe_camera*.py` | 2.1 相机能力探测 |
| `tools/focus_meter.py` | 2.3 手动拧焦验证：实时显示清晰度条形 |

```bash
/root/microscope/run_scope.sh start      # MaixCAM2 上
python3 -m pytest -q microscope/tests    # 电脑上（假相机）
```

## 2.1 相机能力（实测）

| 项目 | 结果 |
|---|---|
| 传感器 | `camera.get_device_name()` = **ov_os04d10**，传感器尺寸 2560×1440（开发方案写的是 OS04A10，以实测为准） |
| RGB888 | 640×480、1280×720 可用（配置 60 帧/秒，实测 40.3、37.1 帧/秒）；1920×1080 及以上报错“RGB888 不得超过 1920x1080” |
| YVU420SP | 1920×1080 27.4 帧/秒；**2560×1440 26.9 帧/秒**，存 JPEG（q95，约 1.06 MB）0.92–0.97 s |
| 第二通道 | `add_channel(1280, 720, YVU420SP)` 硬件缩放：读 33 ms、转 JPEG 20 ms、转灰度 5 ms（软件缩放全图要 374 ms） |
| 锁定曝光 | `exp_mode(Manual)` 后写回 `exposure(e)`：亮度不变（97→97）。**不要写回 `gain(g)`**：读回值从 12365 变成 53762，亮度 97→142 |
| `clear_buff()` | 不支持（只打印警告），取新帧要连续读掉缓冲帧 |
| 注意 | 试 BGR888 高分辨率时进程卡住、被 `timeout` 强杀，之后任何分辨率都报“vi init failed”，重启小智服务无效，**重启 MaixCAM2 才恢复**。因此本服务只用 YVU420SP，停止服务不用 kill |

## 2.2 / 2.3 实测

- 连拍 20 张：20/20 成功，2560×1440，单张 1.27–1.98 s（平均 1.53 s），电脑经 HTTP 取回后 SHA-256 全部一致。
- 拍照期间预览请求 22 次全部成功（最长一次 2.8 s，等拍照存盘）。本服务是显微期间相机的唯一使用者，预览、清晰度、拍照共用同一会话，不在程序间交接相机。
- 清晰度请求：首个 6.0 s（开相机、自动曝光收敛），之后服务端 0.39–0.48 s、往返约 0.52 s；静止画面分数波动 < 1%。
- 相机占用锁：使用中 `camera_is_busy()` 为真；空闲 25 s 后为假，小智可正常拍照。小智占用时本服务最多排队等 8 s。
- **未完成**：手动拧焦“先升后降”需装上显微光路后由人拧焦，用 `tools/focus_meter.py` 记录；2.1 的“教师确认能辨认细胞边界”同样待显微光路。
